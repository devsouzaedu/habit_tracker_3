# Diretrizes do Projeto Habit Tracker v3

## Regras de Versionamento e Fluxo Git
- **Sempre faça Git Commit e Git Push**: Ao concluir qualquer alteração, implementação de nova funcionalidade ou correção de bug neste projeto, sempre faça o commit das alterações com uma mensagem descritiva em português e execute o git push para o repositório remoto (origin/main).
- Mantenha a integridade dos arquivos e verifique a sintaxe antes de commitar.
